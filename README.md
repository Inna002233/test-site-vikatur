# Сайт турагента Виктории (черновик)

Одностраничный сайт-визитка турагента Виктории (Санкт-Петербург, агентство Lady on Travel).

Состояние: **черновик для согласования**. Отзывы в ленте примерные, они помечены на странице как образец и подлежат замене на настоящие. Страница закрыта от индексации поисковиками (`noindex`).

## Файлы
- `index.html` - сама страница (вся разметка, стили и скрипты внутри)
- `brand.css` - цвета и шрифты бренда
- `logo.svg` - временный знак

## Как посмотреть
Откройте `index.html` двойным щелчком в браузере. Нужен интернет для шрифтов Google Fonts и фотографий Unsplash.

## Где менять отзывы
В конце `index.html`, блок `ОТЗЫВЫ ТУРИСТОВ`, список `REVIEWS`. Когда будут настоящие отзывы, поставить `SAMPLE_REVIEWS = false`.
